CodeDojo Daily – DailyDebug Derby

Project Description

CodeDojo Daily – DailyDebug Derby is a web-based coding challenge platform designed to help students improve their programming and problem-solving skills through daily coding challenges.

Objectives

- Improve coding and debugging skills.
- Encourage daily coding practice.
- Support team-based coding activities.
- Display team performance through a leaderboard.

Technologies Used

- HTML
- CSS
- JavaScript

Main Features

1. Daily Coding Challenges
2. Code Editor Interface
3. Team Management
4. Team Leaderboard
5. User-Friendly Interface

How to Run the Project

1. Download the project ZIP file.
2. Extract the ZIP file.
3. Open the project folder.
4. Open "index.html" in Google Chrome.

Future Enhancements

- Backend integration.
- Real-time code execution.
- Multi-user login system.

Conclusion

This project helps students develop programming knowledge, logical thinking, debugging skills, and teamwork abilities.
